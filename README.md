# Logistics & Supply Chain SQL Business Case Study

## 📌 Overview

This project analyzes logistics and shipment data using SQL to answer
real-world supply chain and delivery-related business questions.

## 🎯 Business Objectives

- Analyze shipment volume
- Compare shipping modes
- Identify delivery delays
- Analyze shipping costs
- Identify high-volume customers
- Analyze destination performance
- Measure late-delivery percentage

## 🗂️ Dataset

The dataset contains shipment-level information including:

- Shipment ID
- Order ID
- Customer ID
- Origin
- Destination
- Shipping Mode
- Order Date
- Ship Date
- Delivery Date
- Scheduled Delivery Date
- Shipping Cost
- Shipment Status

## 🧠 SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- HAVING
- CASE WHEN
- ORDER BY
- LIMIT
- Aggregate Functions
- Subqueries
- Window Functions
- RANK()
- Date Functions

## 📊 Business Questions

1. Total shipments
2. Shipments by shipping mode
3. Average shipping cost
4. Late shipments
5. Average delivery delay
6. Top destinations
7. High-volume customers
8. Most expensive shipments
9. Late-delivery percentage
10. Highest-volume month

## 💡 Key Learning

This project focuses on translating logistics business problems
into practical SQL queries rather than simply practicing SQL syntax.
